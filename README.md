# Третьяковка — макет декорации

Интерактивный эскиз театральной декорации.
Два варианта глубины (180/80 см), два цвета, подвижные двери и занавес, экран и технический план.
В варианте 180 см новая картина стоит на деревянном мольберте у переднего края ниши.

Сайт: https://sssss-daily.github.io/tretyakovka-stage-model/

Все зависимости встроены в страницу. Публикация — GitHub Pages, ветка main.
Размеры дополнительных элементов эскизные.
