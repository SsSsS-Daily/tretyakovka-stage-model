# Третьяковка — макет декорации

Сайт: https://sssss-daily.github.io/tretyakovka-stage-model/

Интерактивный эскиз сцены: глубины 180/80 см, два цвета, двери, картина, экран и технический план.
Двигается только дальний центральный занавес. Боковые кулисы двух планов и верхняя драпировка закреплены.
Переднее боковое полотно цельное: у наружного края собрано частыми складками, внутри раскрыто шире.
Добавлен деревянный портал сцены по фотографии.
В варианте 180 см картина стоит на деревянном мольберте у переднего края ниши; в варианте 80 см — на стене.

Все зависимости встроены в HTML. GitHub Pages публикует ветку main.
Дополнительные размеры, подвесы и конструкции эскизные.

Второй план занавеса перекрывает обе боковые двери с прямого ракурса. Полотна перекрываются с соседними планами; двери находятся между вторым и третьим планами и доступны для просмотра сбоку. В интерфейсе есть ракурс «Двери сбоку».

Две боковые двери перенесены в сплошные перегородки между центральной нишей и крайними щитами: в закрытом состоянии перекрывают технический фон, в открытом дают проход. Между вторым и третьим планами занавесов 0,80 м; первый и второй планы сохраняют положение. Ниша вместе с третьим планом сдвинута в глубину на 0,27 м, её размеры сохранены.
До задней стены от ближайшего угла лифта: 1,978 / 2,978 м; до условных опор с выносом 1,25 м: 0,728 / 1,728 м. Это расчёт по эскизной привязке.
