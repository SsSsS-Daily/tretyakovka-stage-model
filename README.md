# Третьяковка — макет декорации, v3 / 08.11.2026

Сайт: https://sssss-daily.github.io/tretyakovka-stage-model/

Один вариант конструкции, два цвета: оливковый и чёрный.
- Длина каждой наклонной боковой стены: 1,80 м вдоль щита.
- От центрального занавеса до задней стены: 1,00 м.
- Центральная стена: 2,20 м; высота стен: 4,00 м.
- Три горизонтальные части стены, стыки на 1,38 и 3,50 м закрыты профильными молдингами.
- Скрытая дверь — отдельная створка в правой стене, эскизно 1,40 × 3,00 м по разметке. Верх и простенки неподвижны, створка открывается на 82°.
- Две боковые двери между вторым и третьим планами сохранены. Двигается только дальний центральный занавес.
- Картина на деревянном мольберте в нише.

Вариант с 80 см убран из текущего макета. Старые ссылки на него открывают актуальную конструкцию.
Ракурс «Стены и молдинги» позволяет рассмотреть стыки и отдельно открыть скрытую створку.
От ближайшего угла лифта до задней стены 2,898 м; до габарита условных опор 1,648 м. Привязка, размеры двери/секций и конструктив эскизные.

Зависимости встроены в HTML. GitHub Pages публикует main, корень репозитория.
